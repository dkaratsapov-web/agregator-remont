# Agregator Remont — дорожная карта и роли

## Модель работы
**Claude Code — единственный разработчик.** Он отвечает за frontend, backend, БД, инфраструктуру, CI, тесты, интеграции, релизы и техническую документацию.
**ChatGPT — независимый ревьюер и архитектурный консультант.** Он не пишет и не меняет код без отдельной просьбы владельца. Проверяет PR, архитектуру, безопасность, полноту ТЗ и риски; сообщает замечания с серьёзностью Critical/High/Medium/Low, указанием файла, причины, теста и способа исправления.
**Владелец продукта** приоритизирует функционал, согласовывает спорные решения и утверждает релизы. PR не объединять без его согласования.

## Архитектура
- pnpm monorepo: apps/web (Next.js, TypeScript, PWA), apps/api (NestJS)
- PostgreSQL + Prisma; S3-совместимое хранилище медиа
- Redis/queue только когда появляется реальная необходимость
- Docker Compose для локальной среды
- GitHub Actions: lint, types, tests, builds, dependency/security scans
- Реальные деньги не храним: платёжный провайдер с подходящей моделью safe-deal после подтверждения условий.
- Не коммитить секреты и пользовательские персональные данные.

## Фаза 0 — инфраструктура и публичный каталог (1–2 недели)
Claude: workspace, Next.js, NestJS, PostgreSQL, Prisma, Docker, CI, оформление сайта, GET /health и GET /v1/jobs, карточка заказа, demo seeds, README.
Приёмка: проект запускается локально по инструкции, web получает реальные данные из API, тесты и CI проходят.

## Фаза 1 — пользователи и тендеры (2–4 недели)
Claude: регистрация, роли, авторизация, RBAC, профили, создание задач, заявки подрядчиков, личные кабинеты, валидация, ограничения доступа, тесты.
Приёмка: пользователь не получает чужие приватные данные; API не доверяет данным о роли с клиента.

## Фаза 2 — коммуникации и сделки без денег (3–5 недель)
Claude: сообщения, файлы, фото-отчёты, moderation/admin, аудит изменений, finite-state deal lifecycle, уведомления.
Приёмка: переходы состояний проверены тестами; доступ к файлам ограничен участниками сделки/админами.

## Фаза 3 — платёжная интеграция и арбитраж (срок зависит от партнёра)
Claude: выбрать и согласовать платёжный провайдер, реализовать sandbox webhook validation, idempotency, payout/refund, reconciliation, журнал финансовых событий, UI конфликтов.
**Гейт:** ни одного настоящего платежа без подтверждённой банковской схемы, юридической проверки и независимого security-тестирования.

## Фаза 4 — релиз и развитие
Claude: PWA, наблюдаемость, резервное копирование/восстановление, перфоманс, эксплуатационные инструкции; затем подписки, поставщики, калькуляторы.

## Каждый Pull Request
- Что изменено, какие требования закрыты, как проверить, результат тестов, миграции, риски.
- Изменения небольшие, без прямых коммитов в main.
- После PR владелец просит ChatGPT провести ревью; ChatGPT пишет замечания, Claude исправляет.
- Ревью ChatGPT — полезная независимая оценка, **не формальный security-аудит**.
