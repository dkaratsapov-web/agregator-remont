# Готовность функций и чеклист запуска

Честная сводка по коду `main` (октябрь 2026, ТЗ #28, P2). **Реализовано** — работает в продукте и
покрыто тестами; **частично** — есть часть сценария; **в планах** — в коде нет, на сайте помечено
«Скоро» или не показывается. Презентация для инвестора описывает продукт целиком, без этих
статусов: при показе клиенту или в КП опираться на эту таблицу.

## Обещания на сайте

- Карточки «Возможности» на главной честно помечены «Работает / Частично / Скоро».
- Безопасной сделки, хранения денег и арбитража в коде нет, и сайт так и говорит: в первом экране
  пункт «Безопасная сделка и помощь в спорах — в разработке», в карточке «Безопасная сделка» и
  в шаге «Принимайте работу по этапам» — «сейчас вы платите мастеру напрямую» (аудит
  23.10.2026, F-01).
- Тест `apps/web/src/components/landing/claims.test.ts` проверяет все исходники сайта: нет фраз
  «гарант качества», «без потери ваших денег», «деньги хранятся», «гарантируем возврат» и
  похожих. `scripts/landing-e2e.mjs` проверяет то же на отрисованной главной.

## Чеклист перед публичным запуском

- [ ] Реквизиты оператора персональных данных, политика обработки, сроки хранения и удаления,
      юридическая проверка — до включения приёма заявок (`PRIVACY_OPERATOR`).
- [ ] Защита ветки `main` в GitHub: обязательный PR, обязательные проверки CI, запрет force-push.
- [ ] Автоматические резервные копии БД вне сервера и проверка восстановления (сейчас вручную,
      `deploy/README.md`).
- [ ] Отчёт `deploy/autodeploy/inventory.sh` с сервера просмотрен.
- [ ] `sudo bash deploy/autodeploy/readiness.sh` на сервере выдаёт «Итог: GO» (защита `main`,
      копии вне сервера, уведомления, монитор, таймеры, HTTPS и ответы сайта, версия, миграции).
- [ ] CSP из report-only в enforce после проверки отчётов. Готово к проверке: отчёты браузеров
      пишутся в журнал web (`csp-violation`), браузерные сценарии CI падают на любом нарушении
      (`docs/SECURITY.md`, раздел 3). Осталось: неделя теста без отчётов, затем переключение.
- [x] Восстановление пароля: ссылка от администратора (`docs/ACCOUNTS.md`); по email — после выбора почтового провайдера.
- [ ] Тексты главной и КП сверены с таблицей выше (что работает, что в планах).
- [ ] Открытый каталог для гостей без контактов (контакты по согласию сторон — сделано:
      `docs/ACCOUNTS.md`, «Контакты по согласию сторон»).
- [x] Аналитика событий без персональных данных (просмотр каталога, черновик, публикация,
      отклик, выбор исполнителя и далее) — `/admin/analytics`, `docs/ANALYTICS.md`.
