Это отчёт о найденном и исправленном, а не заключение «система безопасна». Аудит — чтение
кода, запросы к локальной сборке и автоматические тесты. Внешнего пентеста не было; до
реальных пользовательских данных он нужен (см. `deploy/README.md`, раздел «Перед появлением
реальных пользовательских данных»).

## 2. Проверено, проблем не найдено

Атрибуты cookie (`__Host-`, HttpOnly, Secure, SameSite=Lax); токены сессий (32 байта, в БД
только SHA-256); argon2id и хеш-заглушка для несуществующего email; фильтрация по владельцу и
роли во всех `/v1/me/*` и `/v1/admin/*` (матрица доступа `access-matrix.e2e-spec.ts`); роль
ADMIN только миграцией; проверка Origin во всех Server Actions и изменяющих Route Handlers;
закрытая часть за Caddy `forward_auth`; CORS; заголовки безопасности; загрузка фото (лимиты,
формат по содержимому, без EXIF); только параметризованный SQL; нет
`dangerouslySetInnerHTML`; журналы без тел запросов, токенов и email. `pnpm audit --prod` —
0 уязвимостей (это не доказывает их отсутствие).
