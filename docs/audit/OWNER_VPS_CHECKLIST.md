# Что проверяет владелец на сервере и в GitHub

Дата: 23.10.2026. Этот список закрывает находку F-02 аудита: без него беты нет, и его нельзя
закрыть из кода. Подробные шаги — `docs/OWNER_RELEASE_ACTIONS.md`, порядок выкладки —
`docs/RELEASE_CHECKLIST.md`, итог — `docs/GO_NO_GO.md`.

Правила:
- ни одна команда ниже не печатает пароли, ключи и токены, и их не нужно присылать в чат;
- «только чтение» ничего не меняет; «меняет» — меняет сервер, выполнять осознанно;
- в столбец «Результат» пишется то, что вывела команда (ГОТОВО/НУЖНО, «Итог: GO» и т. п.), а не
  «вроде работает».

## 1. Одна проверка вместо многих (только чтение)

```bash
cd /opt/agregator
read -rs READINESS_GITHUB_TOKEN && export READINESS_GITHUB_TOKEN   # токен только на чтение
sudo -E bash deploy/autodeploy/readiness.sh
unset READINESS_GITHUB_TOKEN
```

Ожидается последняя строка «Итог: GO». Каждая строка НУЖНО называет, что сделать.
